# AxioSozo identity v3

This identity keeps the approved `AXIOSOZO` wordmark and attribution lockup. The square identity remains under exploration in `../concepts-v4/`.

## Primary assets

- `axiosozo-wordmark-primary.svg` / `.png` — horizontal wordmark for light backgrounds
- `axiosozo-wordmark-reversed.svg` / `.png` — horizontal wordmark for dark backgrounds
- `by-axiosozo-primary.svg` / `.png` — attribution lockup for “by AXIOSOZO”
- `by-axiosozo-reversed.svg` / `.png` — reversed attribution lockup

## Ready-to-use files

- `axiosozo-banner-light.png` and `axiosozo-banner-dark.png` — 1600×400 banners

## Usage

Use the horizontal wordmark or attribution lockup wherever space allows. Continue using the original square logo until a new square concept is selected and finalized.

The wordmark identity is intentionally monochrome: ink `#1C1A16`, cream `#F2EAD8`, and white.
